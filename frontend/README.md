# Frontend

Next.js frontend for the FastAPI Blog API.

For full documentation, see **[FRONTEND_DOCUMENTATION.md](./FRONTEND_DOCUMENTATION.md)**.

## Quick start

```bash
npm install
cp .env.example .env.local
npm run dev
```

Ensure the FastAPI backend is running at the URL configured in `NEXT_PUBLIC_API_URL` (default: `http://localhost:8000`).
